Политика конфиденциальности Nuke Net

Дата вступления в силу: 21 августа 2026 года

Настоящая политика описывает обработку данных мобильным приложением Nuke Net, опубликованным разработчиком Nukedo.

Назначение приложения

Nuke Net — клиентское приложение для подключения к сетевым серверам, выбранным пользователем. Приложение использует Android VpnService для создания системного сетевого туннеля. Nukedo не предоставляет пользователям серверы доступа и не продаёт подписки на сторонние сетевые сервисы.

Данные, хранящиеся на устройстве

Добавленные пользователем ссылки подписок, полученные конфигурации серверов, настройки и служебные журналы сохраняются локально на устройстве. Nuke Net не отправляет эти данные разработчику. Локальные данные удаляются при очистке данных приложения или удалении приложения с устройства.

Получение подписки

При обновлении подписки Nuke Net обращается к адресу, который указал пользователь. Поставщику подписки могут передаваться:

  • адрес подписки и содержащийся в нём токен доступа;
  • случайный идентификатор установки Nuke Net;
  • модель устройства, версия Android, язык и регион системы;
  • IP-адрес, неизбежно передаваемый при любом сетевом соединении.

Эти сведения используются для получения совместимой конфигурации и авторизации у выбранного пользователем поставщика. Правила хранения и обработки таких данных определяются владельцем соответствующего сервиса.

Сетевой туннель и VpnService

После явного согласия пользователя Nuke Net использует Android VpnService для направления сетевого трафика через выбранный пользователем сервер. Приложение не записывает историю посещённых сайтов, не анализирует содержимое трафика в рекламных целях и не передаёт его Nukedo.

Выбранный сервер и оператор сети технически могут получать сетевые метаданные, включая исходный IP-адрес и адреса назначений. Обработка трафика выбранным сервером регулируется политикой его владельца. Пользователь должен подключаться только к серверам, которым доверяет.

Проверка задержки

При проверке задержки приложение устанавливает кратковременное TCP-соединение с адресами серверов из подписки. Содержимое пользовательского трафика при такой проверке не передаётся.

Обновления

Версия Nuke Net из Google Play получает обновления через Google Play. Версия, установленная из GitHub, периодически запрашивает публичный файл официального канала обновлений Nuke Net. Соответствующие платформы получают стандартные сетевые данные, включая IP-адрес, согласно собственным политикам конфиденциальности.

Аналитика, реклама и продажа данных

Nuke Net не содержит рекламных или аналитических SDK, не формирует рекламные профили и не продаёт пользовательские данные.

Защита данных

Сетевые конфигурации хранятся в защищённом хранилище Android. Соединение с конечной точкой туннеля использует параметры шифрования, заданные выбранной пользователем конфигурацией. Ни один способ передачи или хранения данных не может гарантировать абсолютную безопасность.

Хранение и удаление данных

Nukedo не ведёт серверную базу учётных записей Nuke Net и не хранит историю пользовательского трафика. Локальные данные можно удалить очисткой данных Nuke Net в настройках Android или удалением приложения. Для удаления сведений, полученных независимым поставщиком подписки или сервером, следует обратиться к владельцу соответствующего сервиса.

Дети

Nuke Net не предназначен специально для детей и сознательно не собирает персональные данные детей.

Изменения политики

Политика может обновляться при изменении функций приложения или требований законодательства. Дата действующей редакции указывается в начале страницы.

Nuke Net Privacy Policy

Effective date: August 21, 2026

This policy describes data handling by the Nuke Net mobile application, published by Nukedo.

Purpose of the app

Nuke Net is a client application for connecting to network servers selected by the user. It uses Android VpnService to create a system-wide network tunnel. Nukedo does not provide access servers or sell subscriptions to third-party network services.

Data stored on the device

Subscription links added by the user, downloaded server configurations, settings, and technical logs are stored locally on the device. Nuke Net does not send this data to the developer. Local data is removed when the user clears the app data or uninstalls the app.

Subscription retrieval

When a subscription is refreshed, Nuke Net contacts the address supplied by the user. The subscription provider may receive:

  • the subscription address and any access token contained in it;
  • a randomly generated Nuke Net installation identifier;
  • device model, Android version, system language and region;
  • the IP address necessarily transmitted with any network connection.

This information is used to retrieve a compatible configuration and authorize access with the provider selected by the user. Retention and processing by that service are governed by its owner’s policy.

Network tunnel and VpnService

After explicit user consent, Nuke Net uses Android VpnService to route network traffic through the server selected by the user. The app does not record browsing history, inspect traffic content for advertising, or send traffic to Nukedo.

The selected server and network operator may technically receive network metadata, including the source IP address and destination addresses. Processing by the selected server is governed by its owner’s policy. Users should connect only to servers they trust.

Latency testing

When testing latency, the app creates a short-lived TCP connection to server addresses contained in the subscription. User traffic content is not transmitted during this test.

Updates

The Google Play version receives updates through Google Play. The GitHub-distributed version periodically requests a public file from the official Nuke Net update channel. Those platforms receive standard network information, including the IP address, under their respective privacy policies.

Analytics, advertising, and sale of data

Nuke Net contains no advertising or analytics SDKs, does not create advertising profiles, and does not sell user data.

Data security

Network configurations are kept in Android protected storage. Connections to tunnel endpoints use the encryption settings provided by the user-selected configuration. No method of transmission or storage can guarantee absolute security.

Retention and deletion

Nukedo does not maintain a Nuke Net account database or retain user traffic history. Local data can be removed by clearing Nuke Net data in Android settings or uninstalling the app. To delete information received by an independent subscription provider or server, contact the owner of that service.

Children

Nuke Net is not specifically directed to children and does not knowingly collect children’s personal data.

Changes to this policy

This policy may be updated when the app’s functionality or legal requirements change. The effective date of the current version appears at the top of this page.
