# Nuke Net for Android

Официальный канал релизов и обновлений Nuke Net для Android.

## Установка

1. Откройте раздел Releases.
2. Скачайте файл NukeNet-Android-0.7.0.apk.
3. Разрешите установку приложений из выбранного браузера или файлового менеджера.
4. Установите APK.

Версии 0.7.0-beta.3 и 0.7.0-beta.4 использовали временную тестовую подпись. Перед установкой стабильной 0.7.0 их нужно один раз удалить.

## Обновления

GitHub-версия Nuke Net проверяет файл stable.json этого репозитория и открывает страницу нового Android-релиза. Google Play использует отдельный магазинный канал обновлений.

Windows-релизы здесь не публикуются.
